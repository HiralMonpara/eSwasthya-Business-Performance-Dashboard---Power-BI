# 📊 eSwasthya Business Performance Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard developed to analyze and monitor the business performance of eSwasthya, an online pharmacy platform. The dashboard helps understand sales performance, customer behavior, order trends, delivery efficiency, and business operations through data visualization.

## 🎯 Project Objectives

- Analyze sales and revenue performance.
- Monitor order completion and cancellation trends.
- Understand customer activity and purchasing behavior.
- Evaluate delivery performance and costs.
- Identify business trends and opportunities for improvement.
- Support data-driven business decision-making.

## 🛠️ Tools & Technologies

- **Power BI** – Interactive dashboards and visualizations
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Microsoft Excel** – Data preparation and analysis

## 📈 Key Dashboard Features

- Sales and revenue analysis
- Order status and completion analysis
- Customer activity and engagement
- Product category performance
- Vendor and purchase analysis
- Delivery performance and cost analysis
- Interactive filters and KPI cards

## 💡 Key Learnings

- Data cleaning and transformation using Power Query
- Creating calculated measures using DAX
- Designing interactive Power BI dashboards
- Analyzing business KPIs and performance trends
- Converting raw data into meaningful business insights

## 🚀 How to View the Dashboard

1. Download the `.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open `esw_Dashboard.pbix` in Power BI Desktop.
4. Explore the interactive visuals, filters, and KPIs.
